# ATM Simulation Using Interface

## Project Title

ATM Simulation System Using Java Interface 

---

## Description

The ATM Simulation System is a simple Java-based desktop application developed using Object-Oriented Programming concepts and Java Swing for graphical user interface design.

This project demonstrates how ATM operations work in a real banking system by allowing users to perform basic banking transactions such as checking account balance, depositing money, and withdrawing money.

The project mainly focuses on the implementation of Java Interfaces, classes, methods, encapsulation, and event handling concepts. The application provides a beginner-friendly and interactive user interface where users can easily perform ATM operations using buttons and dialog boxes.

The system validates user input to avoid invalid transactions such as negative deposits or withdrawing more money than the available balance. Proper messages are displayed for successful and failed transactions.

This project is useful for students to understand:

* Java Interfaces
* OOP Concepts
* Swing GUI
* Event Handling
* Input Validation
* Basic Banking Logic

## How It Works

1. User opens the ATM application.
2. GUI displays different ATM operation buttons.
3. User selects an operation:

   * Check Balance
   * Deposit
   * Withdraw
4. System processes the request.
5. Validation checks are performed.
6. Result message is displayed to the user.

---

## Validation Rules

* Deposit amount must be greater than zero.
* Withdrawal amount must not exceed available balance.
* Invalid numeric input is not accepted.
